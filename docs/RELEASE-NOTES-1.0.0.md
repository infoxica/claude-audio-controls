# Claude Audio Controls 1.0.0

Playback controls for Claude’s native Read aloud replies.

- Pause and resume, seek through received audio, and choose playback speed from 0.5× to 3×.
- Adjust volume, mute, and download completed replies as WAV or WebM/Opus.
- Start with the composer dock, or choose corner, side, and split layouts. Split controls can align with the top or bottom of a tall composer.
- Customize settings with light/dark appearance and 67 interface languages.
- Learn the controls with an optional first-install tour.
- Use the standalone Tampermonkey userscript on Chrome or Edge.

## Getting started

Install the extension, refresh Claude, and start Read aloud on a completed reply. Use either the extension or userscript in a tab.

[Installation guide](https://claude-audio-controls.infoxica.com/installation/) · [User guide](https://claude-audio-controls.infoxica.com/guide/) · [Support](https://claude-audio-controls.infoxica.com/feedback/)

Claude’s native Read aloud must be available on your account. Seeking is limited to received audio; downloads become available when generation completes. Live voice conversations, Firefox, and Safari are not supported.

Audio stays in your browser. The extension has no usage telemetry and requires no additional API key.

# Website screenshots

`native-player.jpg` and `native-controls.jpg` were captured from Claude in Edge on
2026-11-05 with the development extension installed. The example conversation was
created specifically for the demo. The sidebar was hidden before capture.

The first image shows the native chat and the configured side-by-side player;
the second is a screenshot crop of the controls with the volume slider open.
They are actual interface captures, not a recreation of Claude. Claude's interface
and branding belong to Anthropic.

The PNG fixtures generated by browser tests are development evidence. The website
uses the separate `native-*.jpg` captures so running tests cannot replace these
images with the simplified test page.

`layouts/*.png` are generated by `node scripts/capture-layouts.mjs` using the
production player and `scripts/layout-demo.html`, a Claude-style mock with demo
content. It captures eight desktop presets in both rail orders and the mobile
composer layout. These are illustrative layout previews, separate from the
native captures above.

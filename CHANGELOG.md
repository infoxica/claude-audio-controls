# Changelog

## 0.1.0 — development preview

- New Claude native Read aloud WebSocket adapter with owned MediaSource playback.
- Native Opus to WebM downloads and native PCM to WAV downloads.
- Composer dock, alternative layouts, playback controls, settings and 67 languages.
- Shared-source Tampermonkey build and localized static website.
- Separate feedback services, consent-based website analytics integration and gated release tooling.

Live platform acceptance is incomplete; this is not the 1.0.0 production release.
